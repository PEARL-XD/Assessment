# Portfolio asset references

The three local portfolio previews are public images from Digital Marketing Doctor's existing website, included as reference material in this independent assessment concept. They are actual previews of the agency's client work, not invented screenshots or new work created by the candidate.

| Local file                       | Original source                                                                 |
| -------------------------------- | ------------------------------------------------------------------------------- |
| `public/portfolio/raika.webp`    | https://www.digitalmarketingdoctor.com/assets/success-stories/c/raikaph-web.jpg |

| `public/portfolio/dr-pearl.webp` | https://www.digitalmarketingdoctor.com/assets/success-stories/c/drpearl-lp.jpg  |

The source serves WebP image data despite the `.jpg` URLs. Local filenames reflect that format. Each preview is displayed with its corresponding business name. The client name strip uses styled text, not official client logos. Service examples are original HTML/CSS illustrations, explicitly labelled as illustrative.

The source URLs are also retained in `src/data.js`. Result figures and company statistics are reported by the original website; they are not independently verified. Fonts are bundled locally through Fontsource and icons are supplied by Lucide.
